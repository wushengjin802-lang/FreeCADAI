- README 更新为阶段 3。

## 语音输入移除说明

当前版本已移除阶段 3 中的语音文件选择和音频转写功能。

移除内容：

- `语音输入` UI 区域。
- `选择音频` 按钮。
- `转写到需求` 按钮。
- OpenAI-compatible `/audio/transcriptions` 调用逻辑。
- `Speech Model` 设置项。

后续如果重新引入语音，建议放到 SaaS 云端能力中统一处理，插件端只接收转写后的文本。

## 验收步骤

### 模板

1. 打开 `FreeCADAI` 工作台。
2. 在 `常用模板` 中选择 `U32 AI 算力机架`。
3. 点击 `套用模板`。
4. 确认建模需求输入框被填充。
5. 调用 LLM 生成脚本。

### 语音输入移除验证

1. 打开 `生成` 标签页。
2. 确认界面中不再出现 `语音输入` 区域。
3. 确认界面中不再出现 `选择音频` 和 `转写到需求` 按钮。
4. 打开 `设置` 标签页。
5. 确认不再出现 `Speech Model` 配置项。

## 限制

- 当前版本不包含语音输入；所有建模需求通过文本框或模板输入。
- 模板仍是 prompt 模板，不是结构化 DSL 模板。
