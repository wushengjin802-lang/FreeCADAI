## 自动修复流程

```text
用户点击执行脚本
  -> 脚本执行失败
  -> 捕获错误栈和失败脚本
  -> 如果启用自动修复
  -> 调用 LLM 修复脚本
  -> 校验修复后的脚本
  -> 再次执行
  -> 成功则结束
  -> 失败则继续，直到达到最大修复次数
```

默认启用自动修复，最多修复 2 次。UI 中可调整为 0 到 3 次。

## 参数 JSON 重新生成

LLM 返回的 `parameters` 会显示在 `参数 JSON 编辑` 区域。例如：

```json
{
  "length": 100,
  "width": 60,
  "height": 10,
  "hole_diameter": 8
}
```

用户可以改成：

```json
{
  "length": 140,
  "width": 80,
  "height": 12,
  "hole_diameter": 10
}
```

然后点击 `按参数重新生成`，插件会把原始需求、编辑后的参数 JSON 和当前 FreeCAD 上下文发送给 LLM，生成新的脚本。

## 修改当前模型

阶段 2 加强了选中对象上下文。选中对象时，插件会采集：

- 对象 Name。
- 对象 Label。
- TypeId。
- Shape 包围盒。
- Placement 位置。
- 常见尺寸属性，例如 Length、Width、Height、Radius、Diameter。

示例需求：

```text
在当前选中的底板中心增加一个直径 20 mm 的通孔。
```

LLM 会被要求优先使用上下文中的真实对象名，而不是凭空创建对象名。

## 验收步骤

### 自动修复

1. 生成一个脚本。
2. 手动在脚本中制造一个变量错误，例如把已定义变量名改错。
3. 勾选 `执行失败时自动修复`。
4. 设置最多修复次数为 2。
5. 点击 `执行脚本`。
6. 确认插件会自动调用 LLM 修复并重试。

### 参数重新生成

1. 调用 LLM 生成脚本。
2. 在 `参数 JSON 编辑` 区修改尺寸。
3. 点击 `按参数重新生成`。
4. 确认脚本预览区更新。
5. 点击 `执行脚本`，插件会自动校验并执行。

### 修改选中对象

1. 在 FreeCAD 中创建或打开一个对象。
2. 选中该对象。
3. 点击 `查看当前上下文`，确认能看到选中对象信息。
4. 输入修改需求。
5. 生成脚本并确认脚本使用真实对象名。
6. 执行脚本。

## 限制

- 自动修复依赖可用的 LLM API。
- 参数 JSON 重新生成仍由 LLM 根据参数重写脚本，不是本地 AST 级参数替换。
- 当前仍执行受限 Python，不是最终 DSL 沙箱。
